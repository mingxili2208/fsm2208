# Package_1 the discription of the vive_tracker transformation

The main purpose of this package is to perform registration (rigid body transformation) between the coordinate systems of Sandbox and SteamVR.

1. The code is written in Python on the Colab platform.

2. The file test.ipynb contains all the coordinate data used;

3. verify.ipynb includes verification of some key functions;

4. transform_release_v0.2.ipynb is the main part where the least squares problem is solved using SVD.
