# 相关背景信息

## 概述

重庆赛迪奇智，年报显示，是李开复创新工场集团旗下青岛创新奇智公司与五矿集团旗下中冶赛迪合资（年报显示2019年俩公司分别认缴注资510w、490w，2023年认缴出资2550w、2450w）；2022年扩招30人，开始无人轨道车的研发工作。
