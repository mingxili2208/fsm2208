# FSM Sandbox 传感器保真度验证 - 设计说明

## 1. 项目背景与目标

### 1.1. 背景

在自动驾驶仿真中，传感器的“保真度”（Fidelity）或“自洽性”（Self-Consistency）是衡量仿真平台质量的核心指标。一个高保真的虚拟传感器（如LiDAR）应该能生成与虚拟世界物理规律一致的数据。验证这一点对于确保基于该仿真平台开发的感知、定位算法的有效性和可靠性至关重要。

### 1.2. 目标

本项目旨在设计并实现一套完整的、自动化的保真度验证方案，用于评估FSM Sandbox中虚拟LiDAR的性能。核心目标是回答：**“仅使用虚拟LiDAR的点云数据，一个标准的NDT定位算法能否精确地还原出车辆在仿真世界中的真实位姿？”**

具体目标包括：

1. **精确对比**: 同步采集仿真中的地面真值位姿和LiDAR点云数据。
2. **隔离验证**: 通过离线回放点云的方式，独立评估由LiDAR数据质量决定的NDT定位性能。
3. **量化误差**: 精确计算定位结果与地面真值之间的平移误差（毫米级）和旋转误差（度级）。
4. **鲁棒对齐**: 实现一个能容忍微小时间戳抖动的自适应数据对齐算法。
5. **自动报告**: 自动化生成包含统计数据、可视化图表和性能评估的综合分析报告。

## 2. 实验设计与流程

本方案采用“在线采集-离线处理-对比分析”的三阶段流程，以确保变量隔离和结果的可靠性。

```bash
+---------------------------------+      +---------------------------------+      +--------------------------------+
|      阶段一: 在线数据采集        |      |      阶段二: 离线NDT处理       |      |       阶段三: 对比分析         |
|      (Online Collection)        |      |      (Offline Processing)     |      |       (Analysis)               |
+---------------------------------+      +---------------------------------+      +--------------------------------+
| 1. 运行FSM Sandbox完整系统      | ---> | 1. 启动独立的NDT节点            | ---> | 1. 运行 analyze_fidelity_data.py |
| 2. 运行 ground_truth_recorder.py|      | 2. 运行 offline_ndt_recorder.py |      | 2. 输入GT和NDT的CSV文件        |
|    - 输出: ground_truth.csv     |      | 3. 回放录制的LiDAR数据包        |      | 3. 自动对齐、计算、生成报告    |
| 3. ros2 bag record /lidar_topic |      |    - 输出: offline_ndt.csv      |      |    - 输出: PNG图表, MD报告, JSON |
|    - 输出: lidar.bag            |      |                                 |      |                                |
+---------------------------------+      +---------------------------------+      +--------------------------------+
```

## 3. 数据模型与接口

实验涉及两种核心数据，它们的格式保持一致以便于对比。

**CSV文件格式 (`ground_truth_poses.csv`, `offline_ndt_poses.csv`)**

| 列名          | 数据类型 | 描述                                       |
|---------------|----------|--------------------------------------------|
| `timestamp_ns`| int64    | 消息头中的纳秒级时间戳，用于数据对齐的主键 |
| `session_id`  | string   | 实验会话的唯一标识 (YYYYMMDD_HHMMSS)       |
| `x`, `y`, `z` | float64  | 位置坐标 (米)                              |
| `roll_rad`    | float64  | 滚转角 (弧度)                              |
| `pitch_rad`   | float64  | 俯仰角 (弧度)                              |
| `yaw_rad`     | float64  | 偏航角 (弧度)                              |
| `qw`, `qx`, `qy`, `qz` | float64 | 姿态的四元数表示                       |

## 4. 核心组件实现

### 4.1. `ground_truth_recorder.py`

* **职责**: 作为“真值记录员”，订阅并记录仿真世界提供的精确车辆位姿。
* **实现**:
  * 订阅地面真值位姿话题。
  * 在回调中，对收到的每条消息进行时间戳验证和数据提取。
  * 将位姿数据（位置、欧拉角、四元数）及时间戳写入带 `session_timestamp` 的CSV文件。

### 4.2. `offline_ndt_recorder.py`

* **职责**: 作为“离线结果记录员”，在LiDAR数据包回放期间，记录NDT算法的输出。
* **实现**:
  * 逻辑与`ground_truth_recorder.py`类似。
  * 订阅NDT输出的位姿话题。
  * 记录的数据格式与真值文件完全一致，便于后续对比。

### 4.3. `analyze_fidelity_data.py`

* **职责**: 作为“首席分析师”，执行完整的对比分析和报告生成。
* **实现**:
  * **加载与清洗**: 使用`pandas`加载两个CSV，并进行排序、去重。
  * **数据对齐**: 调用核心的`align_data_with_adaptive_window`函数。
  * **误差计算**: 对每一对齐的数据点，计算平移误差（欧氏距离）和旋转误差（归一化角度差）。
  * **统计分析**: 计算误差的均值、中位数、标准差、P95/P99百分位数。
  * **评估与报告**: 调用相应函数，将统计结果与预设阈值比较，并生成PNG图表和Markdown报告。

## 5. 关键算法：自适应时间戳对齐

这是保证分析鲁棒性的核心算法。

* **问题**: 真值数据和NDT输出数据的时间戳并非严格一一对应。
* **解决方案**: 使用`pandas.merge_asof`进行“最近值”合并。
* **自适应机制**:
    1. 定义一个容忍度窗口列表 `tolerance_windows = [10ms, 50ms, 100ms, ...]`.
    2. 从最小的容忍度开始尝试对齐。
    3. 计算对齐成功率（`对齐数量 / NDT总数`）。
    4. 如果成功率低于阈值（如80%），则使用下一个更大的容忍度窗口重新尝试。
    5. 选择第一个达到成功率阈值的对齐结果，或在所有尝试后选择对齐数量最多的结果。

这个机制确保了在不同步情况下的最佳数据利用率。

## 6. 产出物与评估标准

### 6.1. 交付物

每一次分析会生成一个以 `fidelity_analysis_YYYYMMDD_HHMMSS` 命名的结果目录，包含：

1. `fidelity_statistics_...json`: 包含所有统计数据的JSON文件，便于程序读取。
2. `fidelity_error_analysis_...png`: 包含误差时序图和分布直方图的可视化图表。
3. `fidelity_report_...md`: 自动生成的Markdown格式综合分析报告。

### 6.2. 性能评估标准

脚本内置了一套可配置的评估标准，用于自动化判断保真度等级。

| 指标                      | 阈值        | 评估维度       |
|---------------------------|-------------|----------------|
| 平移误差均值 (Mean)       | `< 5mm`     | 准确性 (Accuracy) |
| 平移误差P99 (99th)        | `< 20mm`    | 最坏情况稳定性 |
| 偏航角误差均值 (Mean)     | `< 0.1°`    | 姿态准确性     |
| 偏航角误差P95 (95th)      | `< 0.5°`    | 姿态稳定性     |
| 平移误差标准差 (Std)      | `< 10mm`    | 一致性 (Consistency) |

## 7. 结论

本设计方案提供了一个健壮、自动化、可复现的虚拟LiDAR保真度验证工具链。通过其模块化的设计、智能的数据对齐算法和用户友好的报告输出，能够高效、精确地评估FSM Sandbox的仿真质量，为后续的算法开发和系统优化提供关键的数据支撑。
