### 2. 核心组件

#### 2.1 增强集成管理器 (EnhancedIntegratedManager)

- **职责**: 整体流程控制和组件协调
- **功能**:
  - 系统初始化和资源管理
  - 测试流程执行和状态管理
  - 异常处理和恢复机制
  - 统计信息收集和报告

#### 2.2 CARLA管理器 (CarlaManager)

- **职责**: CARLA仿真器交互和车辆管理
- **功能**:
  - CARLA服务器连接管理
  - Traffic Manager配置和控制
  - NPC车辆生成、配置和清理
  - 车辆行为参数设置

#### 2.3 Autoware目标发布器 (AutowareGoalPublisher)

- **职责**: ROS2/Autoware通信和导航控制
- **功能**:
  - 目标位置发布和管理
  - Engage命令发送和控制
  - 车辆位置监听和距离计算
  - 导航状态监控和反馈

#### 2.4 键盘监听系统 (EnhancedKeyboardMonitor)

- **职责**: 实时键盘输入监听和处理
- **功能**:
  - 多键并发监听 (T/R/P/S/Q)
  - 按键状态管理和重置
  - 按键统计和记录
  - 线程安全的事件处理

#### 2.5 交互式菜单系统 (MenuSystem)

- **职责**: 用户界面和交互逻辑
- **功能**:
  - 主菜单显示和选择处理
  - 参数输入和验证
  - 进度显示和状态反馈
  - 用户确认和提示

### 3. 数据流设计

#### 3.1 导航数据流

用户选择 → 菜单系统 → 集成管理器 → Autoware发布器 → ROS2 → Autoware
                                        ↓
位置反馈 ← 键盘监听 ← 集成管理器 ← Autoware发布器 ← ROS2 ← Autoware

#### 3.2 NPC管理数据流

测试开始 → 集成管理器 → CARLA管理器 → CARLA仿真器
                                      ↓
碰撞检测 → 键盘监听 → 集成管理器 → CARLA管理器 → 车辆清理

## 测试流程设计

### 1. NPC测试流程

起点检查 → 目标设置 → NPC生成 → 导航执行 → 碰撞监控 → 目标到达 → NPC清理

**详细步骤**:

1. 检查车辆是否在NPC测试起点
2. 设置导航目标为任务终点1
3. 生成5辆指定类型的NPC车辆
4. 发送engage命令开始导航
5. 监控导航过程和键盘输入
6. 处理碰撞恢复 (T键触发)
7. 到达终点1后继续到终点2
8. 清理所有NPC车辆

### 2. 回环测试流程

起点检查 → 路点循环 → 中断检查 → 完成统计

**详细步骤**:

1. 检查车辆是否在回环测试起点
2. 按顺序导航到各个回环路点
3. 检查暂停/停止请求 (P/S键)
4. 返回起点完成一次循环
5. 根据设置继续或结束

### 3. 点对点导航流程

当前位置 → 目标设置 → 导航执行 → 到达确认

## 关键算法

### 1. 距离计算算法

```python
def calculate_distance(x1, y1, x2, y2):
    return math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
```

### 2. 位置到达判断

```python
def check_if_at_position(goal_pos, threshold):
    distance = calculate_distance(current_x, current_y, goal_pos, goal_pos)
    return distance < threshold
```
