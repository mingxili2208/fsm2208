# ros_bridge

ROS bridge 是一个连接 CARLA 模拟器和 ROS 的桥梁，实现两者之间的双向通信。它将 CARLA 服务器的信息转换为 ROS topics，同时将 ROS 节点发送的消息转换为 CARLA 中的命令。
