# the config of sensors used by the car

这个JSON文件定义了一组传感器配置，用于在CARLA模拟器中设置自动驾驶车辆的传感器。文件内容包括：

1. 两个RGB相机：
   - ID为"front"和"view"
   - 位置：x=2.0, y=0.0, z=2.0
   - 分辨率：800x600
   - 视场角（FOV）：100度

2. 一个激光雷达（LiDAR）：
   - ID为"lidar1"
   - 位置：x=-0.15, y=0.0, z=2.6

3. 一个GNSS（全球导航卫星系统）传感器：
   - ID为"gnss1"
   - 位置：x=0.7, y=-0.4, z=1.60

4. 一个CAN总线传感器：
   - ID为"can_bus"
   - 读取频率：25Hz

5. 一个高清地图传感器：
   - ID为"hdmap"
   - 读取频率：25Hz

这些传感器配置用于模拟真实自动驾驶车辆上的各种传感器，包括视觉、距离测量、定位和车辆状态信息。每个传感器都有特定的位置和参数设置，以模拟其在车辆上的实际安装位置和性能特征。这些传感器数据将被用于自动驾驶算法的输入，以进行环境感知、定位和决策。
